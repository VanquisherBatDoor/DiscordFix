>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Если вы уверенно понимаете настройки исключений, лучше добавить исключение. При сомнениях рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Настройте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS в настройках самой системы - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/VanquisherBatDoor/zapret-discord-youtube/releases/latest)

3. Откройте свойства скачанного архива и включите пункт "Разблокировать". Для архивов, открываемых через 7-Zip или PeaZip, этот шаг не требуется

4. Распакуйте файлы в каталог, в пути которого нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Чтобы найти рабочую стратегию, откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для автоматического запуска выберите **`service.bat`** -> `Install Service` -> нужную стратегию

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую для себя**

- [**`service.bat`**](./service.bat) - установка автозапуска и дополнительные действия:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из служб
  - **`Check Status`** - просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - изменение режима обхода для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - включение или отключение обхода для сервисов из `ipset-all.txt`.  
  Это может пригодиться при проверке ресурса, который без zapret работает, а с ним - нет.  
  В скобках показывается состояние:
    - `none` - IP-адреса не проходят проверку
    - `loaded` - IP проверяется по списку
    - `any` - фильтруется любой IP-адрес  
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** - замена текущего фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord</ins>
  - **`Check for Updates`** - ручная проверка наличия обновлений
  - **`Run Diagnostics`** - поиск распространённых причин неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность, если приложение внезапно перестало подключаться
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - проверка сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon

## ☑️Частые вопросы и неполадки

### После запуска `general*` ничего не появляется

- При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться winws.exe (обход).  
Если процесса нет, обратитесь к [#522](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues/522)

### Подходящей стратегии нет
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере

Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - Откройте файл `hosts` в созданной папке текстовым редактором, запущенным от имени администратора
  - Вставьте скопированное в конец `hosts` или замените ранее добавленный аналогичный фрагмент
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно записались.

#### Работа не гарантируется. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/VanquisherBatDoor/tg-ws-proxy) либо с любым публичным прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Стратегии не гарантируют постоянную работу.**
> Обнаруженная стратегия может некоторое время работать, а затем перестать действовать.
> В репозитории есть много вариантов обхода. Если ни один не подошёл, создайте собственную стратегию на основе одной из имеющихся и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не сообщает об ошибках

- Проверьте наличие адреса ресурса в списках доменов или IP

- Испытайте другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; устраните ошибки и в конце ответьте Y
- Удалите каталог с zapret
- Загрузите свежую версию со [страницы релизов](https://github.com/VanquisherBatDoor/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите правой кнопкой по архиву, откройте свойства и при наличии нажмите "Разблокировать", затем "Применить" и "ОК"
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов
- Запускайте разные `general`-скрипты и проверяйте интернет-ресурсы. Если выбранный вариант не работает, закройте программу через значок замка в панели задач и попробуйте следующий
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`

### Игра или приложение перестали работать при включённом zapret

- Проверьте, что в `service.bat` параметр `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Используйте инструкцию: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### На Windows 7 требуется цифровая подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё присутствует в службах

1. Найдите имя службы в командной строке Windows, открытой через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не загружается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться
- Переберите остальные стратегии, особенно если раньше всё работало
- См. также [#251](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить именно её
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord
- Проверьте, заработало ли приложение после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если браузер тоже не подключается, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/VanquisherBatDoor/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Игры не работают

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Самый универсальный порядок действий:
- обновите ipset через `service.bat` и включите `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учитывайте, что `ipset any` может нарушить открытие многих сайтов. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`

Если результат не изменился, создайте обсуждение в разделе [Discussions](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли описание своей проблемы

- Создайте обращение [здесь](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Расширить список обхода можно через следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда сеть указана в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети для исключения
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
